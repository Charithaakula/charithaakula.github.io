In this paper, we show that conditioning a mobile manipulation policy on a special temporal feature map enables long horizon reasoning. We start by representing the scene using
[06:44:04] mirror points which are 3D point with latent features. These features are interpolated and decoded to reconstruct dense dynamics. We also represent the articulated robot body as mirror points using its kinematic model URDF. The features are trained offline remain fixed during text execution and only the point position are updated. Remove environment points using object level rigid transform estimate from key point correspondence and we move robbo points using forward kinematics from the current robot state. The map is updated online using only egocentric observation and robbo state. Then we use this feature map as a state input to a BLA policy.
