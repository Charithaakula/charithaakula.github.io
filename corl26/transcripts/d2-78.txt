Rem can answer the question can this morphology reach this pose. So far this has been answered by solving inverse kinematics which for numeric which for arbitrary morphologies means numerically solving a nonlinear system of equations that is expensive and when we iteratively optimize a morphology to cover a workspace or follow a desired trajectory we ask it millions of times. Interestingly, doing such optimizations, we rarely need the joint solution itself. We just need to
[06:50:13] know whether one exists. RAM therefore predicts existence alone. This lets a single model reason over full SC3 poses, generalize across morphologies, account for self collisions, and still answer in nanconds. To train RAM, we generated a data set of 30 billion samples across 30,000 diverse morphologies. Crucially though, most poses in ET3 are trivially unreachable. We restrict sampling therefore to geometrically plausible regions where reachability is not obvious. The data set is also publicly available. On the architecture side, RAM consists of an occupancy network and an encoder. The encoder embeds each morphology sequence of the nav back parameters into a fixed size latent vector. This latent
[06:51:09] vector conditions the occupancy network which predicts whether query pose is reachable. On unseen morphologies and poses, RAM reaches a balanced accuracy of 84%. Outperforming learned inverse kinematics across morphologies by 15 percentage points. At nancond inference, RAM is also over 500 times faster. Because RAM is differentiable, we can optimize morphologies for reachability by simply back propagating through the model instead of differentiating a numerical inverse kinematics solver. This can accelerate morphology optimization by more than an order of magnitude while yielding designs of comparable quality.
