# California Driving Lab

Public URL: https://charithaakula.github.io/driving-practice/

A self-contained static learning course with ten stages, 30 supervised practice exercises, 17 interactive SVG lessons, 72 embedded California handbook illustrations, the full handbook, four adapted official sample sets, and custom mock exams.

Open `index.html` directly or serve this directory with any static server. GitHub Pages serves this folder from the repository's published main branch. There are no build steps, external JavaScript libraries, accounts, analytics, or server components.

## Files

- `index.html`: complete illustrated course, approximately 5.7 MB. The course itself can be downloaded and studied offline.
- `california-handbook-illustrations.zip`: all 72 original images plus source mapping and attribution, approximately 3.9 MB. This optional archive downloads only when selected.

## Progress

Exam/handbook progress and supervised-practice progress are separate browser-local records. They are not uploaded or shared automatically. The two Copy / restore controls move progress between the offline file, devices, and this page. Clearing browser storage removes these records. The practice and review summaries open a copy dialog for sharing at the learner's choice. No personal documents or practice records are embedded in the published page.
